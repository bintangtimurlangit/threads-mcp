# threads-mcp documentation

**threads-mcp** is a [Model Context Protocol](https://modelcontextprotocol.io/) server for **Meta's Threads**, driving a logged-in browser session as **your own account** — reads, writes, and scheduling — over **stdio**, for Hermes Agent, Claude Code, Claude Desktop, Cursor, and other MCP hosts.
